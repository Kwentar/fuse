# Поддержка macOS в общем ядре

Перенос существующего клиента 0.4.1 в модуль `fuse` сохраняет TCP/Noise/Yamux, идентичность, каталог `P2PMessenger`, chat/routes и файловые протоколы 2.1/2.0. `go.mod`, `go.sum` и пустая публичная конфигурация сети не изменены.

- CLI принимает `--gui`: на macOS создаёт резервную копию профиля перед первым запуском новой версии и включает smart routing без перезаписи config. На остальных ОС процедура резервного копирования не выполняется. Версия общего helper приведена к 0.4.1.
- Unix обрабатывает SIGINT и SIGTERM; Windows сохраняет SIGINT. GUI завершает только принадлежащий ему процесс, совместимый внешний helper может быть переиспользован.
- Unix IPC проверяет длину socket path: 103 байта на macOS, 107 на остальных Unix. Не удаляет обычный файл вместо socket; проверяет права профиля и socket. Тестовые пути сокращены с учётом macOS.
- Приватные Unix-файлы открываются с O_NOFOLLOW/O_NONBLOCK, проверяются тип, владелец, права и число ссылок. Это используется для lock и входящих файлов; Windows имеет соответствующий helper с существующими ACL-проверками. Имена исходящих файлов проверяются до добавления в очередь.
- Плановое переоткрытие relay stream 2.1 переносится в цикл передачи: следующий запрос всегда status для сверки подтверждённой позиции. JSON-схемы, поля ACK и fallback 2.0 не меняются.

Добавлены проверки резервной копии/сохранения ID, Unix IPC и файловых прав, файлов размером 0/1/4 МиБ/4 МиБ+1 с чтением SHA-256 с диска, восстановления более 100 незавершённых задач. Новая сборка Windows/Linux проверяется отдельно от исполнения на этих ОС. Фактические результаты — [RUNLOG](../RUNLOG.md#run-macos-import-20261118).
