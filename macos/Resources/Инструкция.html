Fuse 0.4.1 для Mac

macOS 14 и новее · Apple Silicon · SwiftUI и общее Go-ядро 0.4.1 для Windows / Android / macOS.

Подключение к сети

В публичной сборке нет встроенных серверов. Создайте ID, затем укажите свои bootstrap_nodes и relay_nodes в файле ~/Library/Application Support/P2PMessenger/config.json и перезапустите подключение. Если профиль уже был настроен, его серверы сохраняются. Параметры подключения получите у оператора своей сети.

Установка и обновление

  1. Распакуйте архив. Перетащите Fuse.app в «Программы» или откройте из распакованной папки.
  2. При обновлении завершите прежний клиент через ⌘Q. Старая и новая версии не должны одновременно управлять одним профилем.
  3. Откройте новую версию. Существующий Peer ID сохраняется. Перед первым запуском нового ядра делается локальная резервная копия профиля в соседней папке P2PMessenger Backups. Возврат к старому строгому reader после изменения метаданных очереди не гарантируется — восстанавливайте полную копию.
  4. При первом запуске без профиля введите имя и нажмите «Создать ID». Это локальная генерация ключа, без регистрации на сервере.

Данные находятся в ~/Library/Application Support/P2PMessenger. При обновлении не создавайте новый ID. Не удаляйте identity.key. Перед самостоятельной резервной копией завершите приложение и скопируйте всю папку профиля.

Контакты и чат

  1. «Мой ID» → «Копировать ID». Передайте его собеседнику и получите его ID.
  2. Нажмите «+», введите локальное имя и полный Peer ID. Для файлов и LAN-поиска добавьте друг друга.
  3. Выберите контакт. Return добавляет новую строку, ⌘Return отправляет сообщение.
  4. Кнопка с двумя окнами или контекстное меню контакта открывает отдельное окно чата.

Оба приложения должны быть открыты: офлайн-доставки нет. «Доставлено» означает устойчивую запись получателем, не прочтение. При статусе «Исход неизвестен» используйте «Повторить с тем же ID». Имя контакта — ваша локальная подпись, а не проверенное имя владельца.

Папки, фотографии и видео

Нажмите «Файл» и выберите несколько файлов или папок. Можно перетащить выборку из Finder в окно или скопировать файлы в Finder и нажать ⌘V в поле сообщения. Обычный текстовый буфер вставляется как текст.

Перед добавлением папки приложение объясняет: вложенные файлы отправляются по отдельности, без дерева папок. Симлинки пропускаются. Ошибка одного файла не отменяет остальные; замечания доступны в очереди. Фото и видео не пересжимаются — передаются оригинальные байты с SHA-256.

Выборка сохраняется локально с постоянными UUID до вызова ядра. Повтор неопределённого IPC-вызова сохраняет UUID и не создаёт новую задачу. Исходники должны оставаться на месте и не изменяться до завершения.

Очередь

В боковой панели — общая очередь, в чате — очередь контакта. Одновременно отправляются два файла, остальные ждут. Новые файлы можно добавлять во время передачи. Видны подготовка SHA-256, ожидание, подключение, передача, переподключение, пауза и результат, текущие и подтверждённые байты, скорость, процент и маршрут. Общая скорость upload/download сбрасывается после перезапуска.

Выделите строки с ⌘-щелчком или «Выбрать всё», затем нажмите «Пауза выбранных» / «Продолжить выбранные». Без выделения кнопки управляют всей очередью соответствующего окна. После перезапуска активная очередь возобновляется; явно приостановленные задачи остаются на паузе. Перед продолжением файл повторно проверяется по SHA-256. Команды отмены в 0.4 пока нет — используйте паузу.

Общий размер не ограничен настройкой приложения. 4 МиБ — размер блока. Реальные ограничения — диск, файловая система, сеть и int64.

Автоматический приём

Файлы от добавленных контактов принимаются без отдельного вопроса и сохраняются в ~/Downloads/P2PMessenger. В очереди или профиле можно один раз выбрать другую папку. Совпадающие имена получают суффиксы (2), (3) и далее; существующие файлы не заменяются. Файлы не открываются автоматически. «Показать в Finder» выделяет файл в его папке.

Если экспорт не удался из-за места или доступа, карточка показывает «Ошибка автосохранения». Проверенная копия остаётся в профиле; после устранения причины ядро повторит сохранение. Квоты для входящих файлов в этой версии нет.

Маршрут и скорость

Приложение пробует LAN, прямое подключение / NAT traversal и затем relay. Маршрут контакта показан отдельно от общего состояния сети. «Сеть готова» не гарантирует доступность контакта. Протокол 2.1 сохраняет поток между блоками; со старым клиентом используется 2.0. Успешное пробитие любого NAT не гарантируется.

Стенд на одном Mac не измеряет скорость реальной Wi-Fi / Ethernet сети. Физические замеры Windows / Android ↔ Mac проводятся отдельно с разрешения владельца. VPN, Wi-Fi и firewall приложение не перенастраивает.

Фон, сон и выход

Красная кнопка закрывает окно, но продолжает очередь в фоне. Верните окно через Dock. ⌘Q завершает приложение и своё ядро; при незавершённых задачах появляется предупреждение. Внешнее ядро приложение не завершает. После сна состояние обновляется; при сетевой ошибке можно продолжить задачу.

Права и подпись

Сборка несандбоксированная. Разрешите macOS доступ к локальной сети и выбранным папкам в штатном запросе. Отключать firewall или Gatekeeper не нужно.

Используется локальная ad-hoc подпись, без Developer ID и notarization. На другом Mac может потребоваться штатное разрешение запуска в «Конфиденциальность и безопасность». Для обычного распространения владелец должен подписать и нотарифицировать приложение через Apple Developer.

Команды и границы проверок находятся в README и RUNLOG исходного репозитория. Intel и запуск на macOS 14 требуют отдельной проверки.
